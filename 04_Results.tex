\section{Summarized results from Study 1}
The initial goal of this study was to derive a new vector-based representation of phylogenetic trees that may be usable in machine learning frameworks. This led to the development of Phylo2Vec (or phylo2vec)~\cite{penn2025, scheidwasser2025}, a framework for representing phylogenetic tree topologies in the form of integer vectors. Inspired by Yule processes~\cite{steel2001} and tree counting strategies~\cite{knuth1973, rotem1978, proskurowski1980, rohlf1983}, the core idea of phylo2vec is to describe \emph{how} leaves are iteratively added to an existing tree topology. The construction of phylo2vec builds upon the work of Rohlf~\cite{rohlf1983} and Dinh~\cite{dinh2010}, but differs in its edge labelling strategy and, in the case of Rohlf~\cite{rohlf1983}, in preserving the tree-construction process within the vector representation. Beyond this conceptual shift, our contributions were fourfold: (i) rigorous proofs that the vector representation is bijective with the space of binary rooted trees~\cite{penn2025}, (ii) an extended matrix format for incorporating branch length information, (iii) empirical evidence demonstrating its usability for phylogenetic inference, and (iv) robust and open-source software for manipulating phylogenetic trees using this representation~\cite{scheidwasser2025}. % In addition, the simplicity of such a vector format makes it a convenient starting object for phylogenetic tree manipulation, which is showcased in the \texttt{phylo2vec} software package~\cite{scheidwasser2025}. The package also highlights potential avenues for phylo2vec-based phylogenetic inference, including non-traditional optimisation approaches such as (gradient-based \gls{bme} (GradME)~\cite{penn2023}.

% phylo2vec was originally designed with fast sampling, rapid comparison, and efficient compression of phylogenetic trees

The simple constraint of the phylo2vec formulation notably allows for rapid tree sampling, efficient compression, and straightforward comparison of tree topologies. As shown in Fig.~\ref{fig:p2v_sample}, it is notably faster than the widely used tree manipulation libraries \texttt{ete3}~\cite{huerta2016} and \texttt{ape}~\cite{paradis2019}. The distribution of trees generated from phylo2vec sampling is also naturally uniform~\cite{scheidwasser2025c}, similar to the proportional-to-distinguishable-arrangements model~\cite{holman2005}.

phylo2vec also allows for fast comparison of binary trees, as illustrated by the deduplication task in Penn \textit{et al.}~\cite{penn2025}. Beyond equality, two tree topologies can be compared using phylo2vec via a simple Hamming distance between their respective vectors, as described in Section~\ref{methods:p2v_properties}. Through random walks in both phylo2vec and tree spaces, we observed that moves in the phylo2vec space \emph{generally} equated with \gls{spr} rearrangements. Linear correlation with the Hamming distance was highest with the rooted \gls{spr} distance (Pearson's $r$: 0.929), and lowest for distance metrics related to \gls{nni} (Fig.~\ref{fig:p2v_dist}). Yet, performing a single \gls{spr} on a tree may still result in a significantly different vector (Fig.~\ref{fig:p2v_metrics_from_moves}), and vice versa for a single vector move (Hamming distance of one) (Fig.~\ref{fig:p2v_metrics_from_v_single}).

Due to its unidimensional vector nature, an immediate property of phylo2vec is its compact format (Fig.~\ref{fig:p2v_compression}). For tree topologies, a phylo2vec vector occupies less memory than the Newick format for trees with 100 leaves or more, and the compression ratio reaches 6x using 16-bit integers (up to $\approx$ 32,000 leaves) and 3x using 32-bit integers (Fig.~\ref{fig:p2v_vs_nwk_int}). For trees with branch lengths, this compression ranges from 2x (10 leaves, float64) to 5x (10,000 leaves, float32) (Fig.~\ref{fig:p2v_vs_nwk_float}).

Saving thousands of trees, an operation typically performed in Bayesian phylogenetics involving \gls{mcmc} sampling, can also be optimised using phylo2vec. Although standard file compression (e.g., using \texttt{gzip}) already enables some significant savings, saving 10,000 trees in phylo2vec format can be approximately 5 to 50 times more efficient in terms of file size than a plain-text counterpart (Fig.~\ref{fig:p2v_vs_nwk_int_files},~\ref{fig:p2v_vs_nwk_float_files}).

As a proof of concept, we demonstrated the feasibility of likelihood-based phylogenetic inference with phylo2vec using a hill-climbing scheme on four simple \glspl{msa}, three of which pertain to viral genes of Zika and Influenza A (Section~\ref{methods:p2v_evaluation}). The hill-climbing technique, which involves performing tree proposals using phylo2vec vectors and leveraging RAxML-NG~\cite{kozlov2019} for branch length and substitution optimisation based on the proposed vector, was generally able to recover a tree with the same likelihood as RAxML-NG used standalone~\cite{penn2025}. Despite starting from random trees, this scheme only requires a fraction of tree proposals compared to the space of possible trees~\cite{penn2025}, thereby demonstrating that it can efficiently traverse tree space. However, our approach is more prone to being trapped in local optima due to the pulley principle~\cite{felsenstein2004}, whereby multiple rooted trees can have identical likelihoods when they represent different root placements of the same underlying topology. This creates optimisation challenges that are not typically encountered by most likelihood-based methods, which operate with unrooted trees~\cite{kozlov2019, minh2020}.

Overall, the simplicity of such a vector format makes it a convenient starting object for phylogenetic tree manipulation, as showcased in the \texttt{phylo2vec} software package~\cite{scheidwasser2025}. The package also highlights other potential avenues for phylo2vec-based phylogenetic inference, including scripts to calculate the likelihood of a phylo2mat matrix using BEAGLE~\cite{ayres2019} and non-traditional optimisation approaches such as (gradient-based \gls{bme} (GradME)~\cite{penn2023}).

\section{Summarized results from Study 2}
The overarching goal of this study was to evaluate the informational utility of structure-based phylogenetics to complement our understanding of \textit{Betacoronavirus} spike glycoprotein evolution. To this end, we gathered experimental structures from the \gls{pdb}~\cite{berman2000, rose2010} of various species of the \textit{Betacoronavirus} genus. We used Foldseek~\cite{vankempen2024} to translate the structures into discrete-state sequences and build multi-sequence alignments of representative \textit{Betacoronavirus} strains for both amino acid- and structure-derived sequence sets. The alignments cover 32 viruses covering three of the five proposed \textit{Betacoronavirus} subgenera~\cite{woo2023}: \textit{Sarbecovirus} (e.g., SARS-CoV-related viruses), \textit{Merbecovirus} (e.g., MERS-CoV), and \textit{Embecovirus} (e.g., common cold-causing viruses OC43 and HKU1). Using site-wise Shannon entropy~\cite{shannon1948} as a proxy for conservation, we observed consistent conservation patterns across both alignments, notably lower entropy in the S2 subunit (indicating less variability and thus higher conservation) and higher entropy in the \gls{rbd} region (indicating higher variability)~\cite{scheidwasser2025a}. Although this result appears to contradict previous research positing higher conservation in the tertiary structure than in the primary structure of proteins~\cite{illergaard2009}, this may reflect 3Di's sensitivity to minor conformational changes~\cite{fullmer2025}.

Our analysis of the evolution of \textit{Betacoronavirus} spike proteins primarily hinges on mixture multi-tree modelling using \gls{mast}~\cite{wong2024} to analyse the impact of gradual mutation and recombination on their molecular and structural changes~\cite{scheidwasser2025a}. Testing for different numbers of trees, we found that a three-phylogeny model best explained the evolutionary history in both amino acid and structural alignments, according to the \gls{bic}. Both datasets exhibited two trees with decisively higher likelihoods localised to the \gls{ntd} and \gls{rbd} domains of the S1 subunit, respectively~\cite{scheidwasser2025a}. Whereas the third tree generally covered the S2 subunit in the \gls{aa} dataset, no clear preferences emerged for S2 sites in the structural dataset. Notwithstanding structural ambiguities, we will refer to these trees as “\gls{rbd} tree,” “\gls{ntd} tree,” and “S2 tree” based on the regions they primarily cover in the \glspl{msa} for the sake of simplicity. For both alignments, the third tree had the highest class weight, generally indicating that it was the most gene tree-like~\cite{wong2024}. In the \gls{aa} dataset, the short branch lengths observed in the S2 tree from the \gls{aa} dataset reflect the known conservation of this region relative to other spike domains~\cite{degroot1987, bosch2003, deklerk2022}, suggesting that its role in membrane fusion imposes stronger evolutionary constraints. Conversely, in the 3Di alignment, the longer branch lengths in the third tree may either simply reflect the faster evolution of 3Di sites or their lower information quality carried in alpha helical-rich regions~\cite{fullmer2025}. The latter observation is supported by the presence of helix-rich heptad repeat regions in the S2 subunit~\cite{guo2023}.

Next, we used Bayesian logistic regression to analyse the influence of recombination and mutation on a taxon's propensity to bind \gls{ace2}, a key receptor for several betacoronaviruses whose interaction with viral spike proteins is determinant of host susceptibility and cross-species transmission~\cite{li2016, hoffmann2020, starr2022}. In the \gls{aa} dataset, \gls{ace2} affinity was first significantly affected by recombination, as measured by a taxon's contribution to phylogenetic discordance between the \gls{ntd} and \gls{rbd} trees~\cite{scheidwasser2025a}, consistent with prior work linking recombination in the S1 subunit to shifts in receptor usage~\cite{li2020, jackson2022, temmam2022}. Second, gradual adaptation in the \gls{ntd}, measured via a taxon's root-to-tip length in the \gls{ntd} tree, also seemed to positively affect \gls{ace2} binding~\cite{scheidwasser2025a}. This aligns with evidence that the \gls{ntd}, while not a major recombination hotspot~\cite{deklerk2022}, can modulate \gls{rbd} accessibility for \gls{ace2} usage~\cite{meng2022}. However, the structural dataset offers more nuance on these effects, as only the root-to-tip length in the structural \gls{rbd} tree appeared to significantly affect \gls{ace2} binding~\cite{scheidwasser2025a}. We interpret this result as evidence that recombination in the S1 subunit is a force to be reckoned with in modulating \gls{ace2} binding~\cite{li2020, deklerk2022}, and it does not lead to critical changes in the S1 structure, consistent with studies on SARS-CoV-2 suggesting that recombination has not been a dominant driver of its evolutionary history~\cite{boni2020, wells2023}. Instead, \gls{ace2} affinity appears to be shaped primarily by subtle, gradual structural changes within the \gls{rbd}~\cite{wrobel2021}.

\section{Summarized results from Study 3}
The last study of this thesis aimed to detect infection in poultry using a deep learning-based framework to analyse animal behaviour from video data. To this end, we designed a pilot study to assess welfare impairments caused by \textit{E. coli} infection in broiler chickens~\cite{scheidwasser2025c}. Forty broiler chickens were equally divided into a control group and a group infected with a pathogenic strain of \textit{E. coli}. During the infection phase, both groups were monitored using video recordings. Using a deep neural network fine-tuned to track broilers, we extracted several kinematic features pertaining to behaviour, including distance travelled, change in body area, and time spent near the food source. Using validation data from optical flow and physiological biomarkers of inflammation, we provide a proof-of-concept that deep learning-based markerless tracking can be used for the early detection of infection in poultry cohorts. % We posit that this approach constitutes a noninvasive, scalable method to enhance flock health monitoring and biosecurity.

Post-mortem examination confirmed successful infection establishment. Chickens in the infected group, contrary to the control group, displayed hallmark physiological symptoms of acute infection, including lesions in multiple organs, elevated \gls{saa} levels, and high bacterial \gls{cfu} levels~\cite{scheidwasser2025c}.

The multi-animal \gls{dlc} model was successfully fine-tuned to track and estimate animal pose in our video dataset, with an average tracking root-mean-square error of 3.03 pixels on the training set and 8.68 pixels on the testing set, a fraction of the original image size of (1080 $\times$ 1920 pixels)~\cite{scheidwasser2025c}. Behavioural analysis using \gls{dlc}-based tracking revealed substantial differences between the control and infected groups. Bayesian mixed-effects modelling showed that infected chickens were significantly less active than controls, with a 24\% reduction in distance travelled (95\% credible interval (CrI): 6-39\%) and a 23\% reduction in body area change rate (95\% CrI: 4-39\%). Infected birds also spent 41\% less time near food sources (95\% CrI: 24-56\%), suggesting reduced feeding behaviour~\cite{scheidwasser2025c}.

Subsequently, we compared the behavioural features obtained from animal tracking with optical flow, an established technique for monitoring poultry welfare~\cite{dawkins2009, dawkins2012, colles2016, dawkins2017}. We observed a strong positive correlation with the average distance travelled by animals in videos ($r$ = 0.636, $p$ = 0.048), with control groups exhibiting higher mean optical flow and greater behavioural variance than infected animals~\cite{scheidwasser2025c}. This result thus helped validate the plausibility of using tracking-based behavioural features as predictors of \textit{E. coli} infection.

Overall, the validation of this framework against physiological biomarkers and traditional optical flow analyses demonstrated its capability to effectively discriminate between healthy and infected birds. Notably, tracking-based features were sufficient to detect significant behavioural differences between groups within one day of infection~\cite{scheidwasser2025c}. Although this study did not allow for tracking at the individual level due to the lack of preservation of animal identity across videos (see Section~\ref{methods:chicken_stats}), it constitutes a promising avenue for early disease detection in commercial settings.
